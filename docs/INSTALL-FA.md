# راهنمای نصب و راه‌اندازی «زغال پارسیان»

این راهنما برای نصب قالب و راه‌اندازی فروشگاه روی یک هاست واقعی (وردپرس + ووکامرس) نوشته شده است.

## پیش‌نیازها

- PHP 8.0 یا بالاتر
- MySQL 5.7+ یا MariaDB 10.3+
- وردپرس 6.5 یا بالاتر
- گواهی SSL فعال (https)

## ۱) نصب قالب

1. از بخش **Releases** همین مخزن، فایل `zoghal-parsian.zip` را دانلود کن.
2. پیشخوان وردپرس → **نمایش → پوسته‌ها → افزودن پوسته → بارگذاری پوسته**.
3. فایل zip را انتخاب و نصب کن، سپس **فعال‌سازی** کن.

بعد از فعال‌سازی، قالب به‌صورت خودکار واحد پول «تومان» و اجازه‌ی آپلود SVG را به ووکامرس اضافه می‌کند.

## ۲) نصب ووکامرس

پیشخوان → **افزونه‌ها → افزودن → جستجوی WooCommerce** → نصب → فعال‌سازی.

در ویزارد اولیه:

- کشور فروشگاه: **ایران**
- واحد پول: **تومان (IRT)**

اگر ترجمه‌ی فارسی ووکامرس نصب نبود، بسته‌ی ترجمه را از
`https://downloads.wordpress.org/translation/plugin/woocommerce/fa_IR.zip`
دانلود کن و محتوای آن را در `wp-content/languages/plugins/` قرار بده، سپس **به‌روزرسانی‌ها → به‌روزرسانی ترجمه‌ها** را بزن.

## ۳) برگه‌ها و منو

ووکامرس به‌طور خودکار برگه‌های فروشگاه، سبد خرید، تسویه حساب و حساب کاربری را می‌سازد.
عنوان‌ها را به فارسی تغییر بده و این برگه‌ها را هم بساز:

- درباره ما
- تماس با ما
- قیمت روز

سپس **نمایش → فهرست‌ها** و منوی اصلی:

1. صفحه اصلی
2. محصولات (لینک به برگه‌ی فروشگاه)
3. قیمت روز
4. درباره ما
5. تماس با ما

## ۴) ورود محصولات

فایل [`woocommerce-products.csv`](woocommerce-products.csv) شامل ۴ محصول با قیمت، دسته‌بندی، توضیحات و تصویر است.

1. فایل را با یک ویرایشگر متن باز کن.
2. عبارت `YOUR-DOMAIN.com` را با دامنه‌ی خودت جایگزین کن.
3. پیشخوان → **محصولات → همه محصولات → درون‌ریزی** → فایل CSV را بارگذاری و اجرا کن.

اگر تصاویر دانلود نشدند، فایل‌های SVG را از
`wp-content/themes/zoghal-parsian/assets/img/`
به کتابخانه‌ی رسانه آپلود کن و به‌عنوان تصویر شاخص محصول انتخاب کن.

## ۵) حمل‌ونقل و پرداخت

**ووکامرس → تنظیمات → حمل‌ونقل:**

- منطقه‌ی «ایران» بساز.
- روش «نرخ ثابت» با هزینه‌ی دلخواه (یا رایگان) اضافه کن.

**ووکامرس → تنظیمات → پرداخت‌ها:**

- «پرداخت در محل» را فعال کن.
- «کارت به کارت» را فعال و اطلاعات حساب را وارد کن.

## ۶) پیوندهای یکتا و SSL

- **تنظیمات → پیوندهای یکتا → نام نوشته** → ذخیره
- برای SSL از گواهی رایگان هاست یا افزونه‌ی Really Simple SSL استفاده کن.

## ۷) شخصی‌سازی

**نمایش → سفارشی‌سازی → اطلاعات تماس زغال پارسیان:**

- شماره‌های تماس
- آدرس
- ایمیل
- اینستاگرام / واتساپ
- لینک نقشه

متن هیرو، بنر فروش عمده و مزیت‌ها هم از همان‌جا قابل تغییر است.

## ۸) بکاپ

قبل از تغییرات مهم از دیتابیس و `wp-content` بکاپ بگیر.
افزونه‌های پیشنهادی: UpdraftPlus یا BackWPup.

## نکته‌ها

- نسخه‌ی محلی توسعه با SQLite اجرا می‌شود؛ روی هاست معمولاً MySQL است. به همین دلیل فایل دیتابیس محلی مستقیماً قابل انتقال نیست و محتوا با CSV و تنظیمات دستی منتقل می‌شود.
- فونت وزیرمتن از CDN بارگذاری می‌شود. اگر دسترسی به گوگل‌فونت مشکل داشت، فونت را محلی می‌کنیم.
- تصاویر محصولات SVG هستند و قالب خودش اجازه‌ی آپلود آن‌ها را فعال می‌کند.
